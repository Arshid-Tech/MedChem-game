# Pharmacochem Crisis (بحران در فارماکوکم) — MedChem-game

یک بازی آموزشی جدی (Serious Game) و پلتفرم شبیه‌ساز اتاق فرار مجازی برای تدریس مباحث **شیمی دارویی** به دانشجویان دکترای حرفه‌ای داروسازی (مبتنی بر پروپوزال پژوهشی دانشگاه علوم پزشکی البرز).

## معماری و استک فنی (Monorepo)

* **Backend (`/backend`):**
  * Python + Django + Django REST Framework (DRF)
  * احراز هویت مبتنی بر JWT با شماره دانشجویی، نام و نام خانوادگی، و قابلیت تغییر رمز عبور
  * مدل‌های پژوهشی و تحلیلی: ثبت لاگ دقیق هر معما (زمان حل، تعداد خطاها، امتیاز، نشان‌ها/Badges)، جدول رده‌بندی (Leaderboard) و پرسشنامه استاندارد **MEEGA+**
  * آماده برای استقرار روی **Render** و **VPS** (پشتیبانی از PostgreSQL و SQLite در محیط توسعه + Gunicorn + WhiteNoise)
* **Frontend (`/frontend`):**
  * React + TypeScript + Vite + Tailwind CSS (پشتیبانی کامل از RTL و فونت وزیرمتن)
  * رندر تعاملی ساختارهای شیمیایی (SVGهای دقیق استروئیدی با استریوشیمی $\alpha/\beta$ و مکانیک‌های Drag & Drop / Sorting / Docking)
* **Deployment (`/render.yaml` & Dockerfiles):**
  * پیکربندی آماده برای استقرار مستقیم در Render و اجرای Docker روی سرور مجازی (VPS)

## نقشه راه توسعه (Roadmap)
1. **فاز ۱ (پایه و زیرساخت):** معماری Monorepo، احراز هویت دانشجویی، مدل‌های دیتابیس پژوهشی، گیت امنیتی ورود (سنتز هسته سیکلوپنتانوپرهیدروفنانترن) و دپارتمان اول (آزمایشگاه گلوکوکورتیکوئیدها).
2. **فاز ۲:** پیاده‌سازی دپارتمان‌های دوم تا پنجم (مینرالوکورتیکوئیدها، استروژن‌ها، پروژستین‌ها و آندروژن‌ها).
3. **فاز ۳:** مرحله نهایی (مسیر بیوسنتز استروئیدها و سنتز پادزهر اهریمن) + فرم یکپارچه ارزیابی MEEGA+ و داشبورد خروجی پژوهشی (CSV/Excel) برای اساتید.
