# بحران در فارماکوکم (Pharmacochem Crisis) — MedChem-game

**بازی آموزشی جدی (Serious Game) و شبیه‌ساز اتاق فرار مجازی برای تدریس مباحث شیمی دارویی به دانشجویان داروسازی**  
طراحی و توسعه‌یافته بر اساس طرح پژوهشی و فناوری دانشکده داروسازی دانشگاه علوم پزشکی البرز.

---

## معرفی پروژه و سناریو

در بازی **«بحران در فارماکوکم»**، دانشجو در نقش **متخصص ارشد شیمی دارویی** در بخش تحقیق و توسعه (R&D) شرکت داروسازی *Apex Pharma* وارد ماموریتی ۶۰ دقیقه‌ای می‌شود. مدیر سابق بخش R&D (دکتر ارول) پیش از خروج، فرمول ترکیب استروئیدی خطرناکی با نام کد **«پروژه اهریمن»** را در سرورهای آزمایشگاه پنهان کرده است.

دانشجو باید پیش از رسیدن بازرسان سازمان غذا و دارو (FDA)، از گیت بیومتریک عبور کرده، وارد **۵ دپارتمان تخصصی هورمون‌های استروئیدی** شود، معماهای مبتنی بر رابطه ساختار-اثر (SAR)، کانفورماسیون فضایی، متابولیسم و داکینگ گیرنده را حل کند و در نهایت با جمع‌آوری ۵ سرنخ کلیدی، **پادزهر آنتاگونیست** را در اتاق مخفی دکتر ارول سنتز نماید.

---

## ویژگی‌های کلیدی آموزشی و پژوهشی

* **گیت امنیتی ورود (Entrance Gate):** سنتز تعاملی اسکلت پایه استروئید (سیکلوپنتانوپرهیدروفنانترن + زنجیره کتول C17β) با مکانیک Drag & Drop.
* **۵ دپارتمان تخصصی شیمی دارویی:**
  1. **آزمایشگاه گلوکوکورتیکوئیدها:** تنظیم کانفورماسیون استریوشیمیایی هیدروژن‌های اتصال حلقه‌ها ($8\beta, 9\alpha, 14\alpha$) و رتبه‌بندی قدرت ضدالتهابی ۶ مشتق کورتیکواستروئیدی ($5>3>4>6>2>1$).
  2. **بخش مینرالوکورتیکوئیدها:** مقایسه فارماکولوژیک اثرات ضدالتهابی، نیمه‌عمر و احتباس سدیم با فلش‌های $\uparrow/\downarrow$ و تفکیک ۹ ترکیب دارویی بر اساس مسیر تجویز (*سیستمیک، موضعی، استنشاقی*).
  3. **آزمایشگاه استروژن‌ها:** جانمایی چهار ساختار و تکمیل نقشه متابولیسم، طراحی استروژن خوراکی طولانی‌اثر، رتبه‌بندی قدرت، داکینگ زمان‌دار DES در گیرنده استروژن، پیشگیری از تشکیل متابولیت فعال و شناسایی کلاس‌های دارویی.
  4. **بخش پروژستین‌ها:** رمزگشایی دیجیتال کد گاوصندوق بر اساس ویژگی‌های فارماکوکینتیک و طراحی پروژستین خوراکی طولانی‌اثر مشتق ۱۹-نورآندروستان.
  5. **بخش آندروژن‌ها و مهارکننده‌ها:** رتبه‌بندی قدرت ورودی، شناسایی متابولیت ماژور فلوتامید (`2-Hydroxyflutamide`)، انتخاب SARM، اصلاح آندروژنیسیته، دسته‌بندی ۱۰ ترکیب در ۵ کلاس و تشکیل کمپلکس با NADPH در `5α-reductase`.
* **مرحله نهایی (اتاق مخفی و سنتز پادزهر):** تطبیق پنج ساختار با خانواده‌های هورمونی، رمزگشایی مسیر بیوسنتز کلسترول (رمز `CORTICOSTEROID`) و مهندسی معکوس مولکول اهریمن.
* **موتور بازی‌وارسازی (PBL):** تایمر معکوس بحران، امتیازدهی پویا با محاسبه جریمه خطا، اعطای خودکار مدال‌های تخصصی (Badges) برای حل بدون خطای هر دپارتمان و جدول رده‌بندی زنده (Leaderboard).
* **ناوبری و راهنمای تعاملی:** نقشه و نشانگر بخش فعال، مسیر صفحه، راهنمای مرحله‌به‌مرحله با امکان رفت‌وبرگشت یا رد کردن، و نمایه کاربر با آمار بازی و تغییر رمز عبور.
* **ابزار پژوهش و پرسشنامه استاندارد MEEGA+:** ثبت دقیق زمان و خطاهای هر معما برای هر دانشجو، فرم یکپارچه ۲۷ سوالی لیکرت پس از پایان بازی (بدون پاسخ پیش‌فرض و با الزام تکمیل همه سوال‌ها)، محاسبه خودکار ۸ زیرمقیاس و خروجی مستقیم CSV برای تحلیل آماری اساتید.

## معماری فنی (Monorepo)

```text
MedChem-game/
├── backend/                 # Django 5 + Django REST Framework + SimpleJWT
│   ├── accounts/            # مدل دانشجو (شماره دانشجویی، نام، رمز عبور، دموگرافیک)
│   ├── game/                # جلسات بازی، اعتبارسنجی سرورساید معماها، مدال‌ها و رده‌بندی
│   ├── analytics/           # پرسشنامه استاندارد MEEGA+ و خروجی CSV پژوهشی
│   ├── config/              # تنظیمات Django آماده برای Render و PostgreSQL
│   ├── build.sh             # اسکریپت بیلد، جمع‌آوری فایل‌های استاتیک و مایگریشن خودکار
│   └── requirements.txt
├── frontend/                # React 18 + TypeScript + Vite + Tailwind CSS (RTL)
│   └── src/
│       ├── components/
│       │   ├── molecules/   # رندر تعاملی SVG ساختارهای استروئیدی با استریوشیمی α/β
│       │   ├── puzzles/     # کامپوننت‌های تعاملی گیت ورود، ۵ دپارتمان و سنتز پادزهر
│       │   ├── AuthScreen.tsx
│       │   ├── ChangePasswordModal.tsx
│       │   ├── GuidedTour.tsx
│       │   ├── MeegaSurveyModal.tsx
│       │   └── UserProfileModal.tsx
│       ├── api.ts           # کلاینت ارتباط با REST API و مدیریت توکن JWT
│       └── App.tsx          # کنترلر اصلی بازی، HUD، پرونده سرنخ‌ها و نقشه R&D
└── render.yaml              # فایل Blueprint برای استقرار یک‌کلیکی روی Render
```

## راهنمای استقرار رایگان روی Render (Blueprint Deploy)

این پروژه به گونه‌ای پیکربندی شده که با یک کلیک روی پلن رایگان **Render** مستقر شود:

1. وارد حساب کاربری خود در [Render Dashboard](https://dashboard.render.com/) شوید.
2. از منوی بالا روی **New +** کلیک کرده و گزینه **Blueprint** را انتخاب کنید.
3. ریپازیتوری **`MedChem-game`** را متصل کنید (اگر روی برنچ `dev` تست می‌کنید، ابتدا `dev` را به `main` مرج کنید یا در تنظیمات Blueprint شاخه `dev` را انتخاب کنید).
4. Render به‌صورت خودکار فایل `render.yaml` را شناسایی کرده و ۳ سرویس زیر را در پلن رایگان می‌سازد:
   * **`medchem-game-db`:** دیتابیس PostgreSQL رایگان
   * **`medchem-game-backend`:** سرویس وب Django (اجرای خودکار `./build.sh`، مایگریشن‌ها و `gunicorn`)
   * **`medchem-game-frontend`:** استاتیک‌سایت React + Vite متصل به آدرس بک‌اند
5. پس از پایان بیلد (حدود ۳ تا ۵ دقیقه)، لینک سرویس `medchem-game-frontend` را باز کنید، با یک شماره دانشجویی و رمز عبور دلخواه ثبت‌نام کنید و بازی را تست نمایید.

> **نکته درباره پلن رایگان Render:** در پلن رایگان، سرویس بک‌اند پس از ۱۵ دقیقه عدم فعالیت به حالت Sleep می‌رود و اولین درخواست بعدی ممکن است حدود ۳۰ تا ۵۰ ثانیه برای بیدار شدن سرور زمان ببرد.

## راهنمای اجرای محلی (Local Development)

### ۱. راه‌اندازی بک‌اند (Django)
```bash
cd backend
python -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations accounts game analytics
python manage.py migrate
python manage.py createsuperuser  # برای دسترسی به پنل ادمین و دانلود CSV پژوهشی
python manage.py runserver
```

### ۲. راه‌اندازی فرانت‌اند (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
سپس برنامه در آدرس `http://localhost:5173` در دسترس است.

## خروجی داده‌های پژوهشی برای اساتید

پس از تکمیل بازی و ثبت پرسشنامه MEEGA+ توسط دانشجویان:
* پنل مدیریت در آدرس `/admin/` با اطلاعات سوپریوزر در دسترس است.
* از طریق مسیر `/api/analytics/export-csv/` (با دسترسی ادمین) می‌توانید فایل CSV یکپارچه شامل مشخصات دموگرافیک، امتیاز کل، تعداد خطاها، زمان صرف‌شده و نمره تک‌تک سوالات و زیرمقیاس‌های MEEGA+ را دانلود کنید.
