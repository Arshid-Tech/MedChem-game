# بحران در فارماکوکم (Pharmacochem) — کارخانه مولکول دکتر ارول

**بازی آموزشی جدی (Serious Game) و شبیه‌ساز اتاق فرار مجازی برای تدریس مباحث شیمی دارویی به دانشجویان داروسازی**  
طراحی و توسعه‌یافته بر اساس طرح پژوهشی و فناوری دانشکده داروسازی دانشگاه علوم پزشکی البرز.

---

## معرفی پروژه و سناریو

در بازی **«فارماکوکم (کارخانه مولکول دکتر ارول)»**، دانشجو در نقش **متخصص ارشد شیمی دارویی** در ماموریتی ۶۰ دقیقه‌ای وارد کارخانه دکتر ارول می‌شود. دکتر ارول و تیمش در حال کار روی مولکول استروئیدی خطرناکی با نام کد **«اهریمن»** هستند.

دانشجو باید از ورودی کارخانه عبور کرده، وارد **۵ اتاق تخصصی هورمون‌های استروئیدی** (*چنگال استرس، گوله نمک، ماه عسل، نی‌نی کوچولو و ریش و سیبیل*) شود، معماهای مبتنی بر رابطه ساختار-اثر (SAR)، کانفورماسیون فضایی، متابولیسم، داکینگ گیرنده و سنتز تعاملی را حل کند و در نهایت با جمع‌آوری ۵ سرنخ کلیدی، در اتاق مخفی دکتر ارول **پادزهر آنتاگونیست** را سنتز نماید.

---

## ویژگی‌های کلیدی آموزشی و پژوهشی

* **رندر ۲بعدی واقعی ساختارهای شیمیایی (`OpenChemLib` + SMILES):** تمام ترکیبات دارویی به صورت ساختار ۲بعدی استاندارد (با استریوشیمی $\alpha/\beta$ و قابلیت بزرگ‌نمایی) نمایش داده می‌شوند؛ پیش از حل معما نام داروها مخفی است و پس از پاسخ صحیح، نام دارو و نکته آموزشی SAR نمایش داده می‌شود.
* **میز کار سنتز تعاملی و تحلیل زنده SAR (`SteroidSandbox`):**
  * درگ‌اند‌دراپ گروه‌های عاملی روی نقاط اتصال اسکلت استروئید و مشاهده لحظه‌ای تغییرات *قدرت ضدالتهابی، احتباس سدیم، فراهمی زیستی خوراکی، نیمه‌عمر و $\log P$*.
  * قابل دسترسی در تمام صفحات از طریق دکمه شناور **«میز کار مولکول‌سازی»**.
* **سیستم راهنمای پله‌ای ۲ سطحی («مشاوره با مدیر ارشد R&D»):** ارائه نکته مفهومی (سطح ۱) و نکته ساختاری (سطح ۲) به جای آزمون و خطای کور.
* **تایمرهای دقیق پژوهشی (`usePuzzleTimer`):** ثبت دقیق زمان حل هر معما از لحظه باز شدن همان معما بدون جمع مضاعف در تلاش‌های مجدد.
* **ماژول پیش‌آزمون و پس‌آزمون (Pre-test / Post-test):** سنجش رشد یادگیری دانشجو پیش و پس از بازی با محاسبه خودکار `learning_gain_percent` و ارائه پاسخنامه تشریحی پس از پس‌آزمون.
* **ابزار پژوهش و پرسشنامه استاندارد MEEGA+:** فرم ۲۷ سوالی لیکرت بدون پاسخ پیش‌فرض، محاسبه ۸ زیرمقیاس و خروجی یکپارچه CSV شامل دموگرافیک، پیش/پس‌آزمون، عملکرد بازی و MEEGA+ برای تمامی دانشجویان.

```text
Pharmacochem/
├── backend/                 # Django 5 + Django REST Framework + SimpleJWT
```

## استقرار رایگان روی Render (Blueprint Deploy)

1. وارد [Render Dashboard](https://dashboard.render.com/) شوید و از منوی **New +** گزینه **Blueprint** را انتخاب کنید.
2. ریپازیتوری **`Pharmacochem`** را متصل کنید.
3. فایل `render.yaml` به‌صورت خودکار ۳ سرویس زیر را ایجاد می‌کند:
   * **`pharmacochem-db`:** دیتابیس PostgreSQL رایگان (`pharmacochem`)
   * **`pharmacochem-backend`:** سرویس وب Django (`./build.sh` و `gunicorn`)
   * **`pharmacochem-frontend`:** استاتیک‌سایت React + Vite متصل به بک‌اند

---

## راهنمای اجرای محلی (Local Development)

### ۱. راه‌اندازی بک‌اند (Django)
```bash
cd backend
python -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations accounts game analytics
python manage.py migrate
python manage.py createsuperuser  # برای دسترسی به پنل ادمین و دانلود CSV پژوهشی
python manage.py runserver
```

### ۲. راه‌اندازی فرانت‌اند (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
سپس برنامه در آدرس `http://localhost:5173` در دسترس است.
