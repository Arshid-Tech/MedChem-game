# بحران در فارماکوکم (Pharmacochem Crisis) — MedChem-game

**بازی آموزشی جدی (Serious Game) و شبیه‌ساز اتاق فرار مجازی برای تدریس مباحث شیمی دارویی به دانشجویان داروسازی**  
طراحی و توسعه‌یافته بر اساس طرح پژوهشی و فناوری دانشکده داروسازی دانشگاه علوم پزشکی البرز.

---

## معرفی پروژه و سناریو

در بازی **«بحران در فارماکوکم»**، دانشجو در نقش **متخصص ارشد شیمی دارویی** در بخش تحقیق و توسعه (R&D) شرکت داروسازی *Apex Pharma* وارد ماموریتی ۶۰ دقیقه‌ای می‌شود. مدیر سابق بخش R&D (دکتر ارول) پیش از خروج، فرمول ترکیب استروئیدی خطرناکی با نام کد **«پروژه اهریمن»** را در سرورهای آزمایشگاه پنهان کرده است.

دانشجو باید پیش از رسیدن بازرسان سازمان غذا و دارو (FDA)، از گیت بیومتریک عبور کرده، وارد **۵ دپارتمان تخصصی هورمون‌های استروئیدی** شود، معماهای مبتنی بر رابطه ساختار-اثر (SAR)، کانفورماسیون فضایی، متابولیسم، داکینگ گیرنده و سنتز تعاملی را حل کند و در نهایت با جمع‌آوری ۵ سرنخ کلیدی، **پادزهر آنتاگونیست** را در اتاق مخفی دکتر ارول سنتز نماید.

---

## ویژگی‌های کلیدی نسخه ۲ (آموزشی و پژوهشی)

* **رندر ۲بعدی واقعی ساختارهای شیمیایی (`OpenChemLib` + SMILES):** تمام ترکیبات دارویی در دپارتمان‌های ۱ تا ۵ و اتاق مخفی به صورت ساختار ۲بعدی استاندارد (با استریوشیمی $\alpha/\beta$ و قابلیت بزرگ‌نمایی) نمایش داده می‌شوند؛ پیش از حل معما نام داروها مخفی است (حالت بدون اسپویلر) و پس از پاسخ صحیح، نام دارو و نکته آموزشی SAR نمایش داده می‌شود.
* **میز کار سنتز تعاملی و تحلیل زنده SAR (`SteroidSandbox`):**
  * درگ‌اند‌دراپ گروه‌های عاملی روی نقاط اتصال (Hotspots) اسکلت استروئید و مشاهده لحظه‌ای تغییرات *قدرت ضدالتهابی، احتباس سدیم، فراهمی زیستی خوراکی، نیمه‌عمر و $\log P$*.
  * تعبیه‌شده در **دپارتمان ۱ (میز کار آزاد SAR با تشخیص خودکار داروها)**، **دپارتمان ۳ (سنتز استروژن خوراکی)**، **دپارتمان ۴ (سنتز ۱۹-نورآندروستان)** و **مرحله نهایی (مهندسی معکوس و سنتز پادزهر اهریمن)**.
* **سیستم راهنمای پله‌ای ۲ سطحی («مشاوره با مدیر ارشد R&D»):** ارائه نکته مفهومی (سطح ۱) و نکته ساختاری (سطح ۲) به جای آزمون و خطای کور.
* **تایمرهای دقیق پژوهشی (`usePuzzleTimer`):** ثبت دقیق زمان حل هر معما از لحظه باز شدن همان معما بدون جمع مضاعف در تلاش‌های مجدد.
* **ماژول پیش‌آزمون و پس‌آزمون (Pre-test / Post-test):** سنجش رشد یادگیری دانشجو پیش و پس از بازی با محاسبه خودکار `learning_gain_percent` و ارائه پاسخنامه تشریحی پس از پس‌آزمون.
* **ابزار پژوهش و پرسشنامه استاندارد MEEGA+:** فرم ۲۷ سوالی لیکرت بدون پاسخ پیش‌فرض، محاسبه ۸ زیرمقیاس و خروجی یکپارچه CSV شامل دموگرافیک، پیش/پس‌آزمون، عملکرد بازی و MEEGA+ برای تمامی دانشجویان.

## معماری فنی (Monorepo)

```text
MedChem-game/
├── backend/                 # Django 5 + Django REST Framework + SimpleJWT
│   ├── accounts/            # مدل دانشجو (شماره دانشجویی، نام، رمز عبور، دموگرافیک)
│   ├── game/                # جلسات بازی، اعتبارسنجی سرورساید معماها، مدال‌ها و رده‌بندی یکتا
│   ├── analytics/           # پرسشنامه MEEGA+، پیش/پس‌آزمون دانش و خروجی CSV پژوهشی
│   ├── config/              # تنظیمات Django آماده برای Render و PostgreSQL
│   ├── build.sh             # اسکریپت بیلد، جمع‌آوری فایل‌های استاتیک و مایگریشن
│   └── requirements.txt
├── frontend/                # React 18 + TypeScript + Vite + Tailwind CSS (RTL)
│   └── src/
│       ├── components/
│       │   ├── molecules/   # MoleculeStructureCard (OpenChemLib), SteroidMoleculeSVG, SteroidSandbox
│       │   ├── puzzles/     # کامپوننت‌های تعاملی گیت ورود، ۵ دپارتمان، سنتز پادزهر و ProgressiveHintBox
│       │   ├── AuthScreen.tsx
│       │   ├── ChangePasswordModal.tsx
│       │   ├── GuidedTour.tsx
│       │   ├── KnowledgeQuizModal.tsx
│       │   ├── MeegaSurveyModal.tsx
│       │   └── UserProfileModal.tsx
│       ├── utils/           # persian.ts و usePuzzleTimer.ts
│       ├── api.ts           # کلاینت ارتباط با REST API و مدیریت خطاهای شبکه/Render
│       └── App.tsx          # کنترلر اصلی بازی، HUD، پرونده سرنخ‌ها و نقشه R&D
└── render.yaml              # فایل Blueprint برای استقرار یک‌کلیکی روی Render
```

## راهنمای اجرای محلی (Local Development)

### ۱. راه‌اندازی بک‌اند (Django)
```bash
cd backend
python -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations accounts game analytics
python manage.py migrate
python manage.py createsuperuser  # برای دسترسی به پنل ادمین و دانلود CSV پژوهشی
python manage.py runserver
```

### ۲. راه‌اندازی فرانت‌اند (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
سپس برنامه در آدرس `http://localhost:5173` در دسترس است.

## خروجی داده‌های پژوهشی برای اساتید

* پنل مدیریت در آدرس `/admin/` با اطلاعات سوپریوزر در دسترس است.
* از طریق مسیر `/api/analytics/export-csv/` (با دسترسی ادمین) می‌توانید فایل CSV یکپارچه شامل مشخصات دموگرافیک، نمرات پیش‌آزمون و پس‌آزمون، درصد رشد یادگیری، امتیاز کل، خطاها، زمان صرف‌شده و نمره تک‌تک سوالات و زیرمقیاس‌های MEEGA+ را دانلود کنید.
